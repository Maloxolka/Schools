# Анализ доступности учреждений дополнительного образования (УДО) для школ г. Новокузнецк

## Описание проекта
Проект выполняется в Google Colab и направлен на исследование доступности учреждений дополнительного образования (УДО) для школ города Новокузнецк. Основная цель — определить, сколько УДО находится в радиусе 3 км от каждой школы, и визуализировать результаты на карте и в виде графиков.

---

## Данные
Используются два CSV-файла:

1. **Rus_schools_final.csv** – информация о школах, включая:
   - Название школы (`name`)
   - Адрес (`addr`)
   - Географические координаты (`lat`, `lon`)

2. **УДО.csv** – информация об учреждениях дополнительного образования:
   - Название учреждения (`name`)
   - Географические координаты (`lat`, `lon`)
